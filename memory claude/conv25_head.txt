## Konsep Dasar

**Bootstrap** itu framework berbasis **komponen**. Dia sudah sediakan komponen jadi seperti navbar, card, modal, table, form — kamu tinggal pakai class-nya dan langsung muncul. Ibaratnya seperti beli furniture IKEA — sudah jadi, tinggal pasang.

**Tailwind CSS** itu framework berbasis **utility**. Dia tidak kasih komponen jadi, tapi kasih kamu "alat-alat kecil" (utility class) untuk bangun design sendiri dari nol. Ibaratnya seperti beli kayu, paku, dan cat — kamu bentuk sendiri sesuai mau.

## Perbandingan

**Kecepatan development** — Bootstrap lebih cepat untuk prototyping karena komponen sudah siap. Tailwind lebih lambat di awal, tapi setelah terbiasa dan punya komponen sendiri, kecepatannya bisa setara atau lebih cepat.

**Kebebasan design** — Di sinilah perbedaan besar. Bootstrap punya "tampilan khas Bootstrap" yang susah dihilangkan — banyak website akhirnya terlihat mirip. Tailwind kasih kebebasan penuh, setiap elemen bisa kamu design seunik mungkin tanpa harus override style bawaan.

**Untuk standar perusahaan/client** — Tailwind lebih unggul. Perusahaan biasanya punya brand guideline sendiri (warna, spacing, tipografi). Tailwind bisa dikonfigurasi di `tailwind.config.js` supaya semua utility class mengikuti brand guideline. Bootstrap bisa juga tapi harus banyak override CSS, yang sering bikin kode berantakan.

**Ukuran file** — Bootstrap memuat semua CSS-nya sekitar 230KB meskipun kamu cuma pakai 10% komponennya. Tailwind di production cuma memuat class yang benar-benar kamu pakai, jadi file-nya bisa jauh lebih kecil dan website lebih ringan.

**Learning curve** — Bootstrap lebih mudah dipelajari karena tinggal hafalin nama komponen. Tailwind butuh waktu adaptasi karena kamu harus paham CSS properties-nya dulu, baru bisa pakai utility class-nya dengan efektif.

**Maintainability** — Bootstrap sering bikin masalah di project besar karena override CSS menumpuk dan saling bentrok. Tailwind lebih bersih karena style langsung di elemen, tidak ada CSS yang saling timpa.

**Komunitas & tren industri** — Bootstrap sudah lama jadi standar (sejak 2011), tapi tren industri sekarang bergeser ke Tailwind. Banyak perusahaan tech modern dan startup sudah adopsi Tailwind. Framework populer seperti Next.js, Laravel Breeze, dan banyak template premium sekarang default pakai Tailwind.
