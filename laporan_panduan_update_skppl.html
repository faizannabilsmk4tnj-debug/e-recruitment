B. Batasan Perangkat Lunak Terbaru

Perbarui poin-poin batasan sistem Anda dengan memasukkan kualifikasi implementasi framework dan sistem keamanan database terpusat yang diterapkan pada kode program:

  1. Aplikasi E-Recruitment dikembangkan berbasis web menggunakan framework Laravel 11/10, TailwindCSS, dan Vanilla JS.
  2. Sistem memerlukan koneksi internet aktif dan server database MySQL/MariaDB untuk memproses transaksi.
  3. Pembatasan sesi login aktif via tabel sessions mencegah penggunaan akun secara bersamaan (multi-device) demi keamanan data.
  4. Validasi usia minimal pelamar (17 tahun) dan kuota lamaran aktif (maksimal 3 lamaran aktif secara bersamaan) dikontrol langsung di database server via Database Triggers.
  5. Fitur CV Builder memanfaatkan editor HTML dinamis di mana template dasarnya ditentukan oleh HR Master di halaman admin.

Database Trigger: Pembatasan Lamaran Aktif

Trigger ini menjamin aturan bisnis agar satu pelamar hanya boleh memiliki maksimal 3 lamaran aktif secara bersamaan, dieksekusi langsung di MySQL tingkat server:

CREATE TRIGGER before_application_insert
BEFORE INSERT ON applications
FOR EACH ROW
BEGIN
    DECLARE v_active_count INT;
    
    -- Hitung lamaran aktif pelamar
    SELECT COUNT(*) INTO v_active_count
    FROM applications
    WHERE user_id = NEW.user_id AND status IN ('applied', 'shortlisted', 'interview');

    IF v_active_count >= 3 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'Batas maksimal lamaran aktif tercapai (Maksimal 3 lamaran aktif secara bersamaan).';
    END IF;
END;
